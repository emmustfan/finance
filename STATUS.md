# Этапы 4 и 5. Разбор, фонды и выпуск

В приложении реализованы подтверждение переводов с комиссией, ожидание второй стороны, правила и пакетное подтверждение статей, ежемесячные платежи, фонды с шаблонами распределения, обзор и ориентир резерва ИП. Добавлены три области архива и запись в семейный архив для группы macOS.

Проверены сквозные сценарии на вымышленных выписках. Резерв с 50 000 ₽ составляет 3 000 ₽. Проверка фондов дала 120 000 / 70 000 / 50 000 ₽ после распределения и 113 000 / 63 000 / 50 000 ₽ после оплаты. Восстановление проверено на отдельных копиях.

Скрипт сборки создаёт автономный пакет для macOS 13 или новее. Установка на семейном Mac, две учётные записи, физическая печать и запуск KeePassXC проверяются по [ACCEPTANCE.md](ACCEPTANCE.md).

# Этап 3. Импорт и сверка

Доступны ручные операции и пакетный импорт CSV для нескольких счетов. Начальный остаток задаётся на конец дня. Счёт выбирается по совпадению реквизита или вручную. Сопоставление столбцов и строки проверяются перед записью. Импорт учитывает ID в пределах счёта и повтор файла, а совпадения без ID предлагает проверить. Остатки считаются из операций и отображаются в реестре. Остаток из выписки можно сверить с расчётом на ту же дату.

В автоматическом сценарии проверены четыре тестовых файла, повторная загрузка, сохранение одинаковых покупок без ID и расчёт остатков. Форматы реальных выгрузок банков ещё предстоит проверить.

# Этап 2. Счета, активы и доступы

В архив добавлен реестр счетов, инвестиций и имущества. Карточка содержит владельца, организацию, тип, статус, дату и сумму известной оценки или остатка. Сводка группирует известные суммы действующих карточек по категории и валюте. Из карточки можно открыть связанный документ. Для KeePassXC хранится текстовый путь к записи.

Тесты проверяют хранение сумм без округления, раздельную сводку по валютам, сохранение связей после правок документов и восстановление реестра вместе с ними. В интерфейсе проверены создание карточки, переход к PDF и аргументы команды запуска KeePassXC. Открытие установленного KeePassXC на Mac ещё не проверено.

# Этап 1. Карточки документов

Работает создание зашифрованного архива, добавление карточек с PDF и бумажным адресом, поиск по названию, номеру, человеку, типу, меткам и папке. Можно добавить карточку только с адресом или только с PDF. Копия восстанавливает карточки вместе с вложениями. Тестовые личные архивы поддерживают изменение тегов и добавление карточек, включая архивы из ранних версий.

Теги можно задать при добавлении документа и поменять в существующей карточке. Список тегов строится по открытому архиву. Выбранный тег сужает текстовый поиск. Формат сохранённых архивов поддерживает это обновление без преобразования файлов.

В открытом архиве можно изменять поля, теги и создавать копию без повторного ввода пароля. Архив назначает карточкам последовательные номера. Поле «Тип» предлагает стандартные варианты и значения из карточек открытого архива.

Автоматические тесты на Linux проверяют поиск, восстановление карточек и вложений после удаления исходных файлов, пароль при открытии, редактирование старых архивов и отказ при попытке перезаписи из устаревшего окна. Проверены фильтрация по точному тегу, сохранение тегов и номеров при редактировании, собственные типы документов и резервные копии. В карточке можно хранить PDF и несколько фото JPEG или PNG. Опись собирает документы из выбранной бумажной папки и сортирует их по разделу и номеру в папке. Ручная проверка этапа 1 на Mac описана в [README.md](README.md).

Интерфейс на Qt проверен в Linux. Проверены добавление PDF и фото, переключение предпросмотра, добавление и удаление тегов, фильтрация по щелчку на теге, поиск по номеру, создание копии, закрытие архива и переход из описи к карточке. Опись проверена по сгенерированному PDF. При проверке печати фотографии подтверждена передача одностраничного PDF команде печати. Использовались автоматизированные ответы файловых диалогов и парольного запроса. Оформление, системные диалоги и физическая печать на macOS ещё не проверены.

# Этап 0

Прототип создает зашифрованный тестовый архив, показывает PDF, отправляет его в системную очередь печати и восстанавливает архив из проверенной копии.

На облачном Debian пройдены три теста. Проверены отдельные пароли и права нового файла `0600`, отказ при повреждении копии, отказ при попытке перезаписать файл и восстановление после удаления источника. PDFium прочитал текст и отрисовал страницу из восстановленного архива. Синтаксис скрипта сборки проверен Bash. Из облака загружены бинарные зависимости для Python 3.12 на macOS 13 для Intel и Apple Silicon.

Пользователь подтвердил запуск ранней версии на семейном Mac с Python 3.14.10. Повторная проверка актуальной версии на целевом компьютере описана в [ACCEPTANCE.md](ACCEPTANCE.md).

Для перепроверки логики в среде разработки с Python 3.12:

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install --only-binary=:all: -r prototype/requirements.txt
.venv/bin/python -m unittest discover -s prototype -v
```
