# Семейный архив

Семейный архив для macOS 13 и новее. В зашифрованном архиве можно хранить карточки документов, прикладывать PDF, указывать адрес бумажного оригинала и восстанавливать документы из копии.

## Запуск на Mac

1. На странице GitHub нажмите **Code → Download ZIP** и распакуйте архив.
2. Подойдет Python 3.14 или 3.12 с поддержкой Tk. Если Python еще не установлен, скачайте его с [python.org](https://www.python.org/downloads/macos/).
3. В Finder откройте **Запустить.command** двойным щелчком. Появится окно Терминала, затем окно приложения. При первом запуске нужен интернет для установки зависимостей. Последующие запуски из той же папки работают без сети.

Если macOS блокирует открытие и вы доверяете этому репозиторию, после первой попытки откройте **Системные настройки → Конфиденциальность и безопасность** и воспользуйтесь **Всё равно открыть**, если эта кнопка доступна.

## Быстрая проверка

1. Нажмите **Новый архив** и задайте тестовый пароль от 12 символов.
2. Нажмите **Добавить документ**, введите название и номер, например «Договор» и «А-237». Укажите шкаф, папку, раздел и номер в папке. Приложите тестовый PDF и подтвердите сохранение паролем архива.
3. Введите `А-237` в поле поиска. В карточке должны появиться PDF и адрес оригинала.
4. Создайте копию, затем выберите **Восстановить из копии** и сохраните восстановленный архив под новым именем. В нем должны открываться та же карточка и PDF.

Кнопка **Создать тестовый архив** открывает архив с готовым демонстрационным PDF. В нём также можно добавлять карточки и менять теги. Ранее созданные личные тестовые архивы открываются в обновлённом приложении и при первом сохранении переходят на формат карточек с сохранением исходного PDF.

Общий архив с групповыми правами открывается для просмотра. Чтобы редактировать его содержимое в личной копии, выберите исходный архив в **Восстановить из копии** и сохраните под новым именем у себя.

## Теги документов

При добавлении карточки впишите теги через запятую, например `Анна, 2024, Страховка`. Чтобы поменять теги существующей карточки, выберите её и нажмите **Изменить теги…**. Пустое поле при сохранении удаляет все теги карточки.

Выберите нужный тег в списке **Фильтр по тегу** слева. Фильтр находит тег целиком, независимо от регистра. Можно одновременно ввести название или номер в поле поиска. Кнопка **Сбросить** снимает фильтр по тегу.
