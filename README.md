# Семейный архив

Семейный архив для macOS 13 и новее. В зашифрованном архиве можно хранить карточки с PDF и фотографиями, искать бумажные оригиналы по описи папок и восстанавливать документы из копии.

Сквозной сценарий проверки всех этапов и ожидаемые суммы собраны в [ACCEPTANCE.md](ACCEPTANCE.md).

## Запуск на Mac

1. На странице GitHub нажмите **Code → Download ZIP** и распакуйте архив.
2. Подойдет Python 3.14 или 3.12. Если Python еще не установлен, скачайте его с [python.org](https://www.python.org/downloads/macos/).
3. В Finder откройте **Запустить.command** двойным щелчком. Появится окно Терминала, затем окно приложения. При первом запуске нужен интернет для установки зависимостей. Последующие запуски из той же папки работают без сети.

Если macOS блокирует открытие и вы доверяете этому репозиторию, после первой попытки откройте **Системные настройки → Конфиденциальность и безопасность** и воспользуйтесь **Всё равно открыть**, если эта кнопка доступна.

## Быстрая проверка

1. Нажмите **Новый архив** и задайте тестовый пароль от 12 символов.
2. Нажмите **+ Документ**, введите название и выберите тип, например «Договор». Укажите шкаф и папку, приложите тестовый PDF и сохраните карточку. Архив сам присвоит номер `0001`. Если на оригинале есть номер, его можно указать в отдельном поле.
3. Введите `0001` в поле поиска. В карточке должны появиться PDF и адрес оригинала. Через **Изменить…** можно поменять тип или другие поля. В поле типа можно вписать свой вариант. Он появится в списке, пока этот тип используется в архиве.
4. Измените теги и выберите **Действия с архивом → Создать копию…**. Для этих действий в открытом архиве пароль повторно не запрашивается. Затем через **Восстановить из копии…** в том же меню сохраните архив под новым именем. Приложение попросит пароль копии и откроет ту же карточку с PDF.

Кнопка **Закрыть архив** блокирует доступ к документам. При повторном открытии понадобится пароль. Существующим карточкам номера назначаются по порядку. После записи используйте текущую версию приложения для открытия обновлённого архива.

**Действия с архивом → Создать тестовый архив…** открывает пример с документами, демонстрационным PDF, квартирой и четырьмя счетами. В нём можно добавлять карточки и менять теги. Ранее созданные личные тестовые архивы открываются в обновлённом приложении и при первом сохранении переходят на формат карточек с сохранением исходного PDF.

При создании выберите область **Семейный**, **Личный** или **ИП**. Для совместной записи создайте семейный архив в папке группы macOS, настроенной по инструкции [ACCEPTANCE.md](ACCEPTANCE.md).

## Теги документов

При добавлении карточки введите тег и нажмите Enter. Можно вставить сразу несколько тегов через запятую, например `Анна, 2024, Страховка`. Чтобы поменять теги существующей карточки, выберите её и нажмите **Изменить теги…**. Кнопка **×** удаляет отдельный тег при сохранении.

Нажмите на цветной тег в боковой панели, списке документов или карточке. Фильтр находит тег целиком, независимо от регистра, и сочетается с поиском по названию или номеру. Нажмите **Все документы**, чтобы снять фильтр по тегу.

## Фотографии и бумажные папки

- В новой или существующей карточке нажмите **+ Фото** и выберите один или несколько файлов JPEG или PNG. PDF и фотографии могут храниться в одной карточке. Выберите нужное вложение над предпросмотром. **Печать** отправляет его на принтер по умолчанию.
- Нажмите **Бумажные папки…** слева и выберите папку. В описи видны номера карточек, названия, разделы и номера в папке. Двойной щелчок открывает карточку. **Распечатать опись…** открывает системный диалог печати.
- Архив сохраняет исходные файлы вложений в зашифрованном виде. Для открытия архива с фотографиями используйте текущую версию приложения.

Проверка общего доступа, печати и установщика описана в [STATUS.md](STATUS.md). Требования проекта сохранены в [SPEC.md](SPEC.md).

## Счета и активы

Откройте **Счета и активы… → + Счёт или актив**. Укажите владельца, категорию и статус. Остаток или оценку можно ввести с датой и валютой. В реестре суммы действующих карточек показаны отдельно для счетов, инвестиций и имущества, по каждой валюте.

Отметьте связанные документы, например договор и полис. Из карточки актива можно открыть выбранный документ. В поле **Путь в KeePassXC** укажите название базы, группу и запись, например `Семейные доступы → Страхование → Полис квартиры`. Для запуска кнопкой **Открыть KeePassXC** приложение KeePassXC должно быть установлено. Пароли остаются в базе KeePassXC.

Оценка имущества и инвестиционных активов вводится вручную. Остаток счёта с настроенным журналом рассчитывается по его операциям. Архивы с карточками активов открывайте в текущей версии приложения.

## Выписки и операции

1. В **Счета и активы…** создайте по карточке на каждый банковский счёт. Для ручного ввода используйте **+ Операция**. Для выписок откройте **Выписки и операции… → Импорт PDF и CSV…**.
2. Для PDF выберите карточку нужного счёта. Программа определит банк, прочитает операции и заполнит начальный остаток, если его ещё нет. Для CSV заранее задайте начальный остаток на конец дня перед первой операцией и сопоставьте столбцы даты, суммы со знаком и описания. Сохранённый реквизит помогает автоматически выбрать счёт при следующем импорте.
3. Постройте предпросмотр. Строки с повторным ID исключаются. Совпадения по дате, сумме и описанию можно отметить вручную, если это отдельные покупки. При пакетной загрузке изменения записываются после подтверждения всех выбранных файлов. Перед подтверждением исправьте сопоставление столбцов или экспорт, если нужно сохранить строки с ошибками.
4. Сравните расчёт с остатком банка из выписки или воспользуйтесь **Сверить остаток…**. Сравнение выполняется на конец указанного дня. Если в последний день с данными об остатке указано несколько разных сумм, используйте ручную сверку.

Импорт PDF работает локально. Поддерживаются проверенные рублёвые выписки с текстовым слоем из Т-Банка, Озон Банка и Модульбанка. В Модульбанке приложение предлагает отдельно сопоставить каждый счёт с операциями. Счета без движений пропускаются. Перед предпросмотром приложение проверяет, что извлечённые операции сходятся с остатками в PDF. Для сканов и других форматов используйте банковский экспорт CSV.

Для пробной загрузки откройте новый тестовый архив и выберите все четыре файла из папки [examples](examples). Настроенные реквизиты подставят два счёта Т-Банка, счёт Ozon Банка и счёт ИП в Модульбанке. После импорта ожидаются остатки 34 300,00 ₽, 21 000,00 ₽, 2 200,00 ₽ и 23 000,00 ₽ соответственно. В выписке Ozon Банка две одинаковые покупки без ID. Обе сохраняются, а повторная загрузка тех же файлов не прибавляет операций.

Поддерживается CSV с заголовком и разделителем «;», запятой или табуляцией. Сумма находится в одном столбце: списания отрицательные, поступления положительные. Даты можно указать в формате `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`. Примеры в репозитории вымышлены и используют универсальный шаблон. Архивы с операциями открывайте в актуальной версии приложения.

## Разбор, фонды и обзор

В **Разборе операций…** можно подтвердить пару перевода, выбрать статью, запомнить правило и подтвердить несколько предложений вместе. В календаре **Регулярные платежи…** видны суммы по плану и факту. Отчёт показывает комиссии связанных переводов, операции без статьи и ориентир резерва ИП.

В **Фондах и целях…** настройте шаблон и выберите проведённое поступление для распределения. Оплату из фонда связывайте с фактическим списанием. В **Финансы… → Итоги** видны деньги на счетах, резервы и свободная сумма. Кнопка **Активы и ближайшие платежи…** открывает оценки и календарь.

## Личные финансы

Откройте **Финансы…**. Можно начать с пустого архива. Кнопка **+ Операция** предложит создать первый кошелёк, если его ещё нет. Выберите расход, доход или перевод, затем введите положительную сумму. Остаток до первой операции можно указать в той же форме. Для нового кошелька без оценки пустое поле означает ноль. Если в реестре есть оценка на предыдущую дату, приложение использует её как начальный остаток. Когда оценка совпадает с датой операции или позже, укажите сумму непосредственно перед операцией.

- **Справочники…** управляют источниками доходов и статьями расходов. Переименование переносится в историю, правила и регулярные платежи. Статью можно отправить в архив и вернуть. Новое название также можно вписать прямо в операции.
- В **Итогах** выберите месяц, три месяца или свой период. Доходы, расходы и их разница считаются за период. Свободная сумма показывает текущие деньги на счетах за вычетом фондов. Внутренний перевод исключается из доходов и расходов, его комиссия учтётся в расходах.
- В **Кошельках и целях** задайте стоимость и срок цели. Прогресс показывает накопленное, остаток до цели и нужный ежемесячный взнос. **Распределить деньги…** позволяет внести суммы сразу в несколько фондов из свободного остатка или выбранного поступления. В расходе можно сразу выбрать, из какого фонда оплачено.
- В **Инвестициях и вкладах** можно записать тикер, количество, затраты на покупку и ручную оценку позиции с датой. Разница показывает текущую оценку за вычетом введённых затрат. Автоматических котировок и прогноза доходности пока нет.
- Для ChatGPT, Claude или таблицы выберите **Экспорт…** и задайте интервал. JSON содержит операции, суммы по статьям и итоги по месяцам. CSV содержит строки операций. Суммы передаются в сотых валюты, например `12345` для 123,45 ₽. Файл сохраняется локально без шифрования. Названия кошельков заменяются метками, а описания и контрагенты добавляются по выбору.

Архивы с новыми финансовыми данными открывайте в текущей версии приложения.
